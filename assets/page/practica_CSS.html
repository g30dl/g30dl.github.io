Hipervinculos: Abrir nueva pestaña

Un enlace target blank es, como su propio nombre indica, una palabra, frase o imagen que, al ser clicada, lleva a otra web o lugar. No obstante, el aditivo de target blank implica una propiedad bastante peculiar, y es que esta redirección se realiza a través de una pestaña completamente nueva de tu navegador.

Noopener está relacionado con la seguridad. Soluciona un problema de seguridad en los navegadores conocido como "reverse tab nabbing", que permite a un atacante tener acceso parcial a la página anterior y se usa normalmente cuando un enlace está configurado para abrirse en una nueva pestaña con target="_blank". Noreferrer está relacionado con análisis y seguimiento. El valor de referencia muestra la página anterior de donde vino un usuario.
