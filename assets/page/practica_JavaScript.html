Tipos de variables

  • let: Locales - Dentro de una funcion o bloque de programación
  • var: Globales - Las podemos utilizar en cuaquier parte del desarrollo
  • const: son varibles con valores fijos, que no puede cambiar de valores durante su ejecución

Tipos de datos

  • String: Caracteres alfanuméricos
  • Number: valores numéricos
  • Booleano: True/False
  • Arrays: Listas ["Elemento Lista #", "Elemento Lista #2", "Elemento Lista #N"]
  • Object - Diccionarios: NombreDiccionario{"Clave1":Valor1, "Clave2":Valor2, "ClaveN":ValorN}
  • Null - Valor indefinido

Programación en JavaScript

  • Condiciones: if/else
  • Estructuras: Switch
  • Cielos/Bucles: For, while, do-while
  • for... of - para recorrer colecciones (arrays)
  • for... in - para recorrer object/disc (clave)

Momento - Lugar cuando se ejecuta JavaScript

  1. Script dentro del HTML - Script embebido en medio del HTML - (Inline Script Early)
  2. Script dentro de un control - Uso de los atributos en elementos HTML - (Inline Events Handlers)
  3. Script al final (Antes de cerrar Body) - Script embebido al final antes de cerrar el body - (Inline Script Late)
  4. Archivo externo (.js) - Script externo vinculado al html - (External Script)

Eventos programables JavaScript dentro de una página Web

  1. DOMContentLoaded

    Definición: Se dispara cuando el árbol del DOM ha sido completamente cargado y analizado, pero antes de que los recursos externos como imágenes y hojas de estilo hayan finalizado su carga.

  2. load

    Definición: Se dispara en el objeto window cuando la página y todos sus recursos dependientes (imágenes, estilos, scripts externos, etc.) han terminado de cargarse por completo.

  3. unload

    Definición: Se dispara cuando el usuario abandona la página o cierra el navegador. Solo permite realizar operaciones muy sencillas que no involucren demoras o peticiones al usuario.

  4. beforeunload

    Definición: Se dispara justo antes de que la página comience a descargarse. Permite mostrar una advertencia al usuario para evitar la pérdida de datos sin guardar antes de que abandone la página.

  5. visibilitychange

    Definición: Se dispara en el documento cuando el contenido de la pestaña pasa de estar visible a oculto (y viceversa), por ejemplo, cuando el usuario cambia de pestaña o minimiza la ventana.

  6. readystatechange

    Definición: Se dispara en el objeto document cada vez que la propiedad readyState (el estado de carga del documento) cambia a loading, interactive o complete.

  7. fullscreenchange y fullscreenerror

    Definición: **fullscreenchange** se dispara inmediatamente después de que un elemento entra o sale del modo de pantalla completa.
    **fullscreenerror** se dispara cuando ocurre un error al intentar activar el modo de pantalla completa.

  8. copy, cut, paste

    Definición: Eventos del portapapeles que se disparan cuando el usuario realiza las acciones de copiar, cortar o pegar contenido. Permiten interceptar y modificar el texto transferido.

  9. selectionchange

    Definición: Se dispara cuando la selección de texto dentro de un documento o en un elemento que permite edición ha cambiado (se ha modificado el rango seleccionado).

  10. scroll

    Definición: Se dispara cuando el contenido de un elemento (o el documento completo) ha sido desplazado (scroll) por el usuario o mediante un script.
