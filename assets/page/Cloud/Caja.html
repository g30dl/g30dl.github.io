Componentes de la Computadora

Hardware de una PC

Una computadora está formada por componentes físicos que trabajan juntos para procesar información. Cada pieza tiene una función específica y vital.

Componentes Principales:

  1. CPU (Procesador) - El cerebro de la computadora
  2. Memoria RAM - Almacenamiento temporal y rápido
  3. Tarjeta Madre (Motherboard) - Conecta todos los componentes
  4. Disco Duro o SSD - Almacenamiento permanente
  5. Tarjeta Gráfica (GPU) - Procesa imágenes y videos
  6. Fuente de Poder - Suministra energía eléctrica

El procesador puede ser Intel o AMD, mientras que las GPU más populares son NVIDIA y AMD Radeon.

Dispositivos de Entrada

  • Teclado
  • Mouse o Ratón
  • Micrófono
  • Escáner
  • Cámara web

Dispositivos de Salida

Monitor - Muestra la información visual

Impresora - Produce documentos físicos

Bocinas o Auriculares - Reproducen audio

Componentes Adicionales:

  • Tarjeta de Red - Conexión a Internet
  • Unidad Óptica - Lee CD/DVD
  • Sistema de Refrigeración - Mantiene temperatura adecuada
  • Case o Gabinete - Protege los componentes internos

Cada componente es esencial: Sin memoria RAM la PC no puede ejecutar programas, sin procesador no hay cálculos, y sin disco duro no hay donde guardar archivos.

Conocer los componentes ayuda a mantener y mejorar tu computadora
